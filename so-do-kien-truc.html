Bulk Import (Excel upsert)

Nhập sản phẩm hàng loạt từ Excel/CSV. Nếu SKU hoặc ID đã tồn tại → update; nếu chưa có → create theo dữ liệu của hàng.

Quy tắc xác định bản ghi

Ưu tiênKhoá kiểm traGhi chú
1idNếu có id hợp lệ → cập nhật đúng bản ghi đó.
2sku (nếu có) → map sang slugTrong DB, trường duy nhất tương ứng là slug. Nếu file có cột sku, hệ thống dùng làm slug.
3slugNếu không có sku nhưng có slug → dùng làm khoá.
4Không có id/sku/slugTạo mới; slug sẽ sinh từ name (kebab-case, unique).

Các bước xử lý

  1. Tạo import_jobs (status=queued), ghi file gốc.
  2. Đọc từng hàng → chuẩn hoá header (ví dụ: sku/SKU).
  3. Xác định khoá theo bảng bên trái; upsert vào products.
  4. Ghi import_items cho từng hàng (status: ok/error, mapped_id).
  5. Cập nhật counters + trạng thái job (running → finished).

Pseudocode

// Input: rows from Excel (XLSX/CSV)
for row in rows:
  keyId   = row.id?.trim()
  keySku  = row.sku?.trim()
  keySlug = row.slug?.trim() or slugify(row.name)

  // 1) Resolve target record
  if keyId and exists(Product[id=keyId]): target = Product[id=keyId]
  else if keySku and exists(Product[slug=keySku]): target = Product[slug=keySku]
  else if keySlug and exists(Product[slug=keySlug]): target = Product[slug=keySlug]
  else target = new Product()

  // 2) Map fields allowed theo schema products
  target.name = row.name
  target.slug = keySku or keySlug
  target.brand_id = row.brand_id
  target.category_id = row.category_id
  target.short_description = row.short_description
  target.overview_html = row.overview_html
  target.spec_json = parseJSON(row.spec_json)
  target.main_image_url = row.main_image_url
  target.dimension_image_webp_url = row.dimension_image_webp_url
  target.price_regular = toDecimal(row.price_regular)
  target.stock_qty = toInt(row.stock_qty)
  target.in_stock = toBool(row.in_stock)
  target.status = row.status
  target.published_at = toTimestamp(row.published_at)
  target.seo_title = row.seo_title
  target.seo_description = row.seo_description
  target.seo_keyword = row.seo_keyword

  save(target)
  writeImportItem(job_id, row_no, status="ok", mapped_id=target.id)
catch (e):
  writeImportItem(job_id, row_no, status="error", error_message=e.message)
Validation gợi ý: bắt buộc name; slug duy nhất; brand_id/category_id phải tồn tại; URL đúng định dạng; spec_json hợp lệ. Cho phép "partial update": cột nào trống thì bỏ qua (không ghi đè).

API – Products CRUD (JSON, remote)

Cung cấp API REST để tạo/đọc/sửa/xoá sản phẩm từ xa bằng JSON. Xác thực Bearer token, hỗ trợ idempotency với header Idempotency-Key.

Endpoints

MethodPathMô tả
GET/api/v1/productsList + phân trang (page, per_page, q, brand_id, category_id, status)
POST/api/v1/productsTạo mới (body JSON theo schema)
GET/api/v1/products/:id_or_slugChi tiết theo id hoặc slug
PUT/PATCH/api/v1/products/:id_or_slugCập nhật toàn phần / từng phần
DELETE/api/v1/products/:id_or_slugXoá mềm (status=private hoặc hard delete theo cấu hình)

Auth & headers

  • Authorization: Bearer <token>
  • Content-Type: application/json
  • Tùy chọn: Idempotency-Key: uuid (POST/PUT an toàn khi retry)
  • Phản hồi có ETag + hỗ trợ If-Match cho cập nhật lạc quan.

Schema JSON (trích)

{
  "name": "string",                      // required
  "slug": "string",                      // unique; nếu không có sẽ sinh từ name
  "brand_id": 1,
  "category_id": 10,
  "short_description": "string",
  "overview_html": "<p>...</p>",
  "spec_json": {"key": "value"},
  "main_image_url": "https://...",
  "dimension_image_webp_url": "https://...",
  "price_regular": 123.45,
  "stock_qty": 5,
  "in_stock": 1,
  "status": "publish",                   // publish|draft|private|future
  "published_at": "2025-01-01T00:00:00Z",
  "seo_title": "string",
  "seo_description": "string",
  "seo_keyword": "string"
}

Ví dụ gọi API

curl -X POST https://yourdomain.com/api/v1/products \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: 6f9a7c2e-1a8f-4d86-af20-6a6e7a3e7dd1" \
  -d '{
    "name": "Thermo TX100",
    "slug": "tx100",
    "brand_id": 2,
    "category_id": 11,
    "price_regular": 1999.00,
    "stock_qty": 3,
    "in_stock": 1,
    "status": "publish"
  }'
Gợi ý triển khai: Chuẩn hoá response theo JSON:API ({ data, meta, errors }), phân trang kiểu meta: { total, page, per_page }, log audit_logs cho mọi thay đổi, và phát webhook product.updated khi POST/PUT/PATCH/DELETE thành công.
